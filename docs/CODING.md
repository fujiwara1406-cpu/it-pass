# コーディングの進め方

> Cursor（AI）を外側から乱暴に使いながら進める。  
> 学習の地図: `docs/STUDY_PLAN.md`

---

## いまの範囲（第1周）

**HTML を書いて → 公開するまで。**  
それ以外の種類のファイルや技術の話は、学習では扱わない（STUDY_PLAN の鉄則）。

| ファイル | 役割 |
|----------|------|
| HTML（例: `index.html`） | 今いじる対象 |
| `docs/TASK.md` | **今やる1タスク** |
| `docs/STUDY_PLAN.md` | Cursor → Git → HTML → 公開 |
| `docs/DEPLOY.md` | 公開手順 |

第2周から: データベース（`docs/DATABASE.md`）。

---

## 動き方

```
1. docs/TASK.md を開く（今の1タスクだけ）
2. Cursor に意図を雑に投げる
3. ブラウザで HTML を確認する
4. わかった言葉を LEARNING.md に1行
5. 区切りで Git にセーブ → 公開は DEPLOY.md
```

自分の役割は **意図を言う・結果を見る・履歴を残す**。

---

## 進捗の残し方

- タスク完了 → `docs/TASK.md` を更新
- 学んだこと → `docs/LEARNING.md` に1行
- 判断・変更 → `docs/HISTORY.md` に追記
