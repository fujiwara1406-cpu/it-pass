# 学習メモ

外側からAIで進めながら、出てきた言葉だけここに残す。
地図: `docs/STUDY_PLAN.md`（第1周: Cursor → Git → HTML → 公開／第2周: DB）
※ 第1周では HTML 以外の技術名はメモに無理に書かない

---

## 使い方

- 新しい用語を知ったら → 1行でいいのでメモ（先に教科書は読まない）
- 「〇〇とは？」と聞いたら → AIが答えつつ、この一覧に1行追記する
- エラーで詰まったら → 原因と解決方法をメモ
- タスク完了時 → `docs/TASK.md` の ✅ を更新

---

## メモ一覧

### 2026-07-22

| 用語 / トピック | 意味・メモ |
|-----------------|------------|
| Cursor | コードを書く・直すためのアプリ。中にAIチャットがあり、「こうしたい」と頼める。いま開いているこれがそれ |
| Cursor と ChatGPT | ChatGPTは会話中心のAIサイト。Cursorは「自分のフォルダの中」でAIがファイルを読んだり直したりできる編集アプリ |
| VS Code | Microsoft製のコード編集アプリ。Cursorの土台。AIチャットが最初から強く組み込まれているのがCursor |
| テキストエディタ | 文字（テキスト）を書く・直すアプリの総称。メモ帳もその一種。VS CodeやCursorは高機能なテキストエディタ |
| 拡張機能 | VS Code / Cursor に後から足せる追加機能（色付け・便利ボタンなど）。必須ではない |
| IDE | Integrated Development Environment（統合開発環境）。テキストエディタに、実行・確認・補助機能がまとまった作業場。Cursor / VS Code はこれに近い |
| VS Code の分類 | 高機能テキストエディタ／軽めのIDE。Microsoft製。Cursorの土台。拡張機能で機能を足せる |
| README | プロジェクトの「取扱説明書」。普通は README.md。何のフォルダか・どう動かすかを最初に書く |
| AGENTS.md | AI（Agent）向けの説明書。READMEが人用、AGENTS.mdはCursorなどのAIに「どう振る舞うか」を伝える。今の it-pass にはまだ無い |
| .cursor | プロジェクト内の Cursor 用フォルダ。中身例: rules/（常時ルール）, hooks（自動処理）, skills/（手順スキル）。見本あり |
| skill | AI向けの「やり方メモ」。特定の言い方をしたとき、決めた手順だけを実行する（例: 用語メモ → LEARNING.md に1行追記） |
| Keep / Undo | CursorでAIの変更を見るとき。Keep=残す（採用）、Undo=なかったことにする（元に戻す） |
| Git | ファイルの変更履歴を残す仕組み。いつ・何を変えたかを記録し、前の状態に戻せる |
| GitHub | Gitのプロジェクトをインターネット上に置くサービス。コードの保存・共有の倉庫 |
| Hub | 「中心・集まり場」の意味。GitHub は Git の Hub＝Gitのプロジェクトが集まる場所、という名前 |
| リポジトリ | Gitで管理しているプロジェクト一式の置き場（履歴つきのフォルダ）。GitHub上の倉庫もリポジトリと呼ぶ |
| プロジェクト | ひとまとまりの作業・成果物。今の it-pass フォルダ全体のような「作っているもの一式」 |
| フォルダ | ファイルを入れる箱（入れ物）。中に別のフォルダも入れられる。Macでは「フォルダ」、Windowsでは「フォルダ／ディレクトリ」とも言う |
| ディレクトリ | フォルダと同じ意味。コンピューターやコマンドでは「ディレクトリ」と呼ぶことが多い |
| ルート | いちばん上のフォルダ（起点）。このプロジェクトなら it-pass 本体のフォルダ。英語の root（根っこ） |
| HTML | HyperText Markup Language。ウェブページの骨組みを書く言葉。見出し・段落・リンクなどの「何がどこにあるか」をタグで示す |
| コミット | Gitで「ここまでの変更を履歴として保存する」こと。セーブポイントのようなもの。メッセージを添えて残す |
| GUI | Graphical User Interface。画面のボタンやメニューを見て操作する方式。対になるのは文字だけのCLI |
| CUI | Character User Interface。文字（キーボード入力）だけで操作する方式。ターミナルがその例。GUIの対。CLIとほぼ同じ意味で使われることが多い |
