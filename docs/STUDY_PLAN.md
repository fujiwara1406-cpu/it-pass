# 学習ロードマップ（外側から・AIで殴る）

> 教科書を積み上げない。**Cursor に雑に頼んで、HTMLをネットに出す。**
> わからない用語は出てきた瞬間に1行メモ（`docs/LEARNING.md`）。
>
> **第1周の一本道:** Cursor → Git → HTML → デプロイ（公開）  
> **第2周:** データベース

---

## 鉄則（公開まで）

| やる | やらない・知らせない |
|------|----------------------|
| Cursor に頼む | **CSS**（見た目の話は出さない） |
| Git でセーブする | **JavaScript / JS**（動きの話は出さない） |
| HTML だけ書く・直す | アプリ全体の複雑さに手を出す |
| Netlify で公開する | 「きれいに動く完成形」を最初の目標にする |

**公開するまで、学習の対象は HTML だけ。**  
フォルダに他のファイルがあっても、今は見ない・触れない・聞かない。

---

## 方針（このノリ）

| やること | やらないこと |
|----------|--------------|
| AIに「こうしたい」とぶつける | 先にいろいろ勉強してから作る |
| 壊れたら貼って直させる | 全部自分で書いてから聞く |
| まず URL を1つ出す | 完成アプリを最初から理解する |

**乱暴に使う＝雑に投げていい。ただし「何をしたいか」は自分の言葉で言う。**  
AIの答えを鵜呑みにせず、ブラウザで開いて自分の目で見る。

---

## 第1周のゴール

**HTML ファイルをネットに公開して、URLで開ける。**

```
Cursorで会話できる
    ↓
Git で「今の状態」を残せる
    ↓
HTML が「画面の骨」だと分かる
    ↓
ローカルで HTML が開く
    ↓
Netlify などで公開 → URL が手に入る  ← 第1周クリア
```

---

## 第1周で使う道具（これだけ）

| 道具 | 役割（一言） |
|------|--------------|
| **Cursor** | AIと一緒にファイルを直す場所 |
| **Git / GitHub** | 変更の履歴・バックアップ |
| **HTML** | 画面の骨組み（見出し・文章・リンクなど） |
| **Netlify** | ネットに置く箱（デプロイ） |

```
[ブラウザ]  ← HTML →  [Netlify に置いたファイル]
```

これ以外の言葉は、第1周では出さない。

---

## フェーズ（第1周）

### Phase A — Cursor を相棒にする（目安 1〜2日）

- このプロジェクトを Cursor で開く
- 「HTMLを書いて」「こう直して」と雑に投げる
- 自分は **意図を言う・結果を確認する** 役

到達点: Cursor に頼んで HTML が変わり、ブラウザで差が見える。

---

### Phase B — Git をセーブポイントにする（目安 半日〜1日）

1. 変更をコミット（「なぜ残すか」を一言）
2. GitHub に置く（あれば）
3. 壊したときに戻せる、と知る

到達点: 公開前の状態が履歴に残っている。

※ コマンドは覚えなくてよい。Cursor に「コミットして」と頼んで、何が起きたかだけ見る。

---

### Phase C — HTML だけ触る（目安 1〜数日）

触ってよいのは **HTML**（例: `index.html` のようなファイル）。

やることの例:

- タイトル・見出し・段落を書く
- リンクを1つ置く
- 「自分のページ」と言える最低限の1枚を作る

到達点: HTML が「画面に何を出すかのメモ」だと体感できる。

---

### Phase D — ローカルで開く（目安 半日）

HTML をブラウザで開いて確認する（ファイルをダブルクリックでも、簡単なローカル起動でも可）。

到達点: 自分のマシンでページが見える。

---

### Phase E — デプロイして公開する（目安 半日）← **第1周のゴール**

1. Netlify Drop などに HTML を置く（手順は `docs/DEPLOY.md`）
2. URL をブラウザで開く
3. URL をメモする（`docs/APP_SPEC.md` や README など）

到達点: **誰でも開ける公開URLがある。**

## 第2周 — データベースを学ぶ

公開が終わってから入る。第1周では触れない。

|----------|------|
