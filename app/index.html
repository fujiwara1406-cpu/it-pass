データベースに接続できません

いまはブラウザ内のローカル保存でも使えます。Supabase を使う場合のみ下を実施してください。

  1. Supabase → SQL Editor で data/supabase_fix.sql を実行
  2. Supabase → Settings → API Keys を開く
  3. Legacy anon タブの anon キー（eyJ...）をコピー
  4. app/js/config.js の SUPABASE_ANON_KEY に貼り替え
  5. ブラウザを再読み込み

Publishable キー（sb_publishable_...）だけでは動かない場合があります。
