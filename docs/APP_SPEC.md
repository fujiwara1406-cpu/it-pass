# アプリ仕様：ITパスポート 一問一答クイズ

> **2026-07-27 更新（コア＋AI 完成モード）**

---

## 概要

| 項目 | 内容 |
|------|------|
| アプリ名 | ITパスポート 一問一答クイズ |
| 種類 | 問題を登録して解けるWebアプリ |
| 技術 | HTML / CSS / JavaScript + Supabase（PostgreSQL）+ Netlify Functions（AI） |
| 公開 | フロント+Functions: Netlify ／ DB: Supabase |
| コード | `app/` |

---

## 目的

ITパスポートの勉強用に、自分で問題を登録して繰り返し解けるアプリ。AIで問題案も作れる。

---

## 機能

| 機能 | 説明 | 状態 |
|------|------|------|
| 問題登録・編集・削除 | CRUD（Supabase） | 実装済み |
| 問題一覧 | 登録済み問題を表示 | 実装済み |
| クイズ出題 | ランダム1問ずつ表示 | 実装済み |
| 正誤判定 | 正解/不正解を表示 | 実装済み |
| スコア・正答率 | 正解数 / 出題数 | 実装済み |
| キー/スワイプ操作 | PC: 十字キー / スマホ: スワイプ | 実装済み |
| AI問題生成（自動） | Netlify Function → OpenAI | 実装済み（要 `OPENAI_API_KEY`） |
| AI問題生成（手動） | プロンプトコピー → JSON貼付 → 一括登録 | 実装済み |

---

## 画面構成

```
┌─────────────────────────────┐
│ ITパスポート 一問一答        │
├─────────────────────────────┤
│ [登録] [AI生成] [クイズ]     │
├─────────────────────────────┤
│ ■ 登録タブ … 問題 CRUD       │
│ ■ AI生成タブ … 問題作成      │
│ ■ クイズタブ … 出題・スコア  │
└─────────────────────────────┘
```

---

## データベース設計（Supabase）

### テーブル: `questions`

| カラム | 型 | 説明 |
|--------|-----|------|
| id | uuid | 主キー（自動） |
| body | text | 問題文 |
| choice_a | text | 選択肢A |
| choice_b | text | 選択肢B |
| choice_c | text | 選択肢C |
| choice_d | text | 選択肢D |
| correct | text | 正解（'A' / 'B' / 'C' / 'D'） |
| created_at | timestamptz | 作成日時（自動） |

---

## AI生成の入出力

入力: キーワード / 参考文 / 件数（3・5・10）

出力 JSON 例:

```json
[
  {
    "body": "問題文",
    "choice_a": "...",
    "choice_b": "...",
    "choice_c": "...",
    "choice_d": "...",
    "correct": "A"
  }
]
```
